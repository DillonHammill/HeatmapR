# Print a heatmap description as wrapped text

Print a heatmap description as wrapped text

## Usage

``` r
# S3 method for class 'heat_map_description'
print(x, width = getOption("width"), ...)
```

## Arguments

- x:

  object of class `heat_map_description` returned by
  [`heat_map_describe`](https://dillonhammill.github.io/HeatmapR/reference/heat_map_describe.md).

- width:

  width of the wrapped text, set to the console width by default.

- ...:

  not used.

## Value

`x`, invisibly.
